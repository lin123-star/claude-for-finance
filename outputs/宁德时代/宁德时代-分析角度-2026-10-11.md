2. **单位价格与成本传导**：FY2025 销量增速明显高于收入增速，动力、储能分部同样如此，而两分部毛利率仅微降（F-volume-FY2025、F-revenue-FY2025、F-power-FY2025、F-storage-FY2025）。2026H1 各主要分部毛利率同比下降（F-power-2026H1、F-storage-2026H1、F-gm-2026H1）。价格与成本谁先动，是利润弹性最大的变量。

4. **非经营项（次要）**：联营合营投资收益、其他收益、资产减值、汇兑（F-invest-FY2025、F-impair-FY2025、F-fx-2026H1）。扣非与归母增速同向同幅（F-deducted-np-FY2025、F-np-FY2025、F-deducted-np-2026H1、F-np-2026H1），暂不构成主驱动。

## 入选角度

### A1 2026H1 份额上升而毛利率全面回落，是让价换份额、成本时滞，还是结构下移？

- 互斥机制：
  - **机制 A 主动让价换份额**：国内单位售价降幅大于单位成本降幅，份额继续上升，毛利率不随后续季度回升。现有证据中，境内毛利率下降、境外毛利率上升、国内乘用车份额大幅提升，与该机制相容（F-overseas-2026H1、F-share-2026H1）。
  - **机制 B 原材料成本上行与价格联动时滞**：单位成本先升，售价按联动条款滞后调整，毛利率在后续季度回升且份额不回吐。该机制预期境内外同时受压；境外毛利率反升对它不利，但若境外合同联动周期更短则未被排除。电池材料及回收、矿产资源分部收入 +67.23%、毛利率 +5.81 个百分点（F-materials-2026H1）只能作为「上游价格可能上行」的假设信号，底账无原材料价格事实。
  - **机制 C 产品结构下移**：同一产品价格稳定，但低单价产品（如入门车型配套、低价储能）占比上升，拉低平均毛利率。
- 判别证据：
  - 已有：F-gm-2026H1、F-power-2026H1、F-storage-2026H1、F-overseas-2026H1、F-share-2026H1、F-materials-2026H1、FY2025 对照 F-power-FY2025、F-storage-FY2025、F-volume-FY2025。
  - 缺失：2026H1 分动力 / 储能销量（GWh），用于算单位收入；营业成本构成中原材料占比；产品结构披露；2026 年第三季度报告的毛利率（可判别 A 与 B：B 应回升，A 不应回升）；同业同期毛利率（底账未收录）。
  - 口径提醒：F-gm-2026H1 为分行业口径，只与其同比数比较，不与 F-gm-FY2025 的计算口径直接比较。
- 主责：competitor-analyst。补充一：financial-analyst，补营业成本构成（原材料、人工、折旧）的同比变化。补充二：valuation-expert，在 A1 结论出来后，只回答「三种机制分别对应的毛利率中枢假设如何改变估值区间」，不得先于 A1 结论启动。
- 访调时可直接问的一句话：上半年国内动力电池毛利率下降，单位售价下降、原材料联动滞后、产品结构变化三者各贡献多少，三季度是否已经回升？

### A2 2026H1 利润高增而经营现金流几乎不增，是订单备货、原材料囤货，还是回款条件恶化？

- 互斥机制：
  - **机制 A 订单驱动的在途 / 发出商品与成品备货**：存货增量主要是库存商品与发出商品，对应已签合同，下半年转为收入与现金；合同负债应同步上升或保持高位。
  - **机制 B 原材料战略囤货**：存货增量主要是原材料，是对上游价格的主动判断；现金消耗是一次性的，但带来存货跌价风险（FY2025 已有资产减值损失 F-impair-FY2025）。
  - **机制 C 下游信用条件放宽、回款变慢**：应收账款周转变慢、账龄后移、应收票据或供应链金融使用上升，反映对下游议价权减弱；与 A1 的机制 A 相互印证。
  - 三者若同时存在，按对经营现金流缺口的贡献排主次，不合并。
- 判别证据：
  - 已有：F-np-2026H1、F-ocf-2026H1、F-revenue-2026H1、F-inv-FY2025、F-inv-2026H1、F-ar-FY2025、F-ar-2026H1、F-ocf-FY2025、F-warranty-2026H1（预计负债增加属非现金计提，会抬高经营现金流，需在拆解中扣除其影响）。
  - 缺失：半年报存货附注分类（原材料 / 在产品 / 库存商品 / 发出商品）及跌价准备；应收账款账龄与周转；应付账款与应付票据（底账未收录，无法判断上游付款条件变化）；合同负债；2026 年第三季度现金流量表。
- 主责：financial-analyst。补充：制造业专项，只补「存货增量与在手订单、交付节奏是否对应」的访调证据。
- 访调时可直接问的一句话：上半年新增存货中原材料、库存商品和发出商品各占多少，对应的订单是否会在年内确认收入并回款？

### A3 储能收入增速未跑赢行业出货，是降价、份额流失，还是产能优先给动力？

- 互斥机制：
  - **机制 A 份额大致稳定、单价下行**：公司储能 GWh 增速与行业相当，收入增速落后来自单价下行；储能毛利率下降（F-storage-2026H1）与之相容。
  - **机制 B 份额被竞争对手蚕食**：公司储能 GWh 增速低于行业，在招投标或大客户中丢单。
  - **机制 C 产能约束下主动控制储能接单**：产能利用率高位（F-capacity-2026H1），公司把产能优先分配给份额正在上升的动力业务（F-share-2026H1），储能在手订单多于交付。B 与 C 的区别在于需求端是否流失：C 下在手订单与预收应充足，B 下不充足。
- 判别证据：
  - 已有：F-storage-2026H1、F-storage-FY2025、F-power-2026H1、F-industry-2026H1、F-share-2026H1、F-share-storage-FY2025、F-volume-FY2025、F-capacity-2026H1。
  - 缺失：2026H1 公司储能 GWh 销量；储能份额百分数（年报与半年报均未给）；鑫椤资讯与 SMM 原始出版物（底账缺口，行业数据只能用公司援引）；储能在手订单与合同负债；行业口径（电芯出货量）与公司口径（系统收入）的换算。
- 主责：competitor-analyst。补充：macro-researcher，只补「SMM 电芯出货量口径与公司系统收入口径能否对比，以及储能需求是否处于周期高点」。
- 访调时可直接问的一句话：上半年储能电池出货 GWh 同比增长多少，是否因为产能紧张而主动控制了储能接单？

### A4 在建产能跃升与资本开支加速，是统计口径变化、订单锁定的扩产，还是超前扩产？

- 互斥机制：
  - **机制 A 统计口径变化**：半年报 525GWh 为半年值或不同口径，764GWh 在建可能包含此前未计入的项目；按底账提醒，不得把 321GWh 到 764GWh 直接解释为在建产能翻倍（F-capacity-2026H1 备注）。若成立，X6 的「拐点」大部分消失。
  - **机制 B 订单锁定的扩产**：新增在建产能有客户长协、预付款或合资方出资对应，利用率在投产后仍能维持高位。
  - **机制 C 无订单对应的超前扩产**：以抢份额、压制二线为目的，投产后利用率下行、折旧上升，与 A1 机制 A 的让价相互强化。
  - B 与 C 只在 A 被排除或修正口径后才有意义。
- 判别证据：
  - 已有：F-capacity-FY2025、F-capacity-2026H1、F-capex-FY2025、F-capex-2026H1、F-lev-2026H1、F-bonds-2026H1、F-cash-2026H1。
  - 缺失：两期产能统计口径说明（底账缺口）；在建产能的地区与项目拆分；在建工程附注；合同负债与长协；债券募集资金用途。
- 主责：走制造业专项（high-end-manufacturing-screener），不另造代理。补充：financial-analyst，只补在建工程、合同负债与应付债券募资用途三项附注。
- 访调时可直接问的一句话：半年报 525GWh 产能与 764GWh 在建产能的统计口径是什么，与年报 772GWh 怎么对应，在建部分有多少已有客户长协或预付款？

### A5 FY2025 综合毛利率上升而两大分部毛利率微降，抬升来自哪里？

- 互斥机制：
  - **机制 A 三分部之外的其他收入高毛利**：底账三分部之外仍有收入未列示，若这部分毛利率高且同比扩大，FY2025 的综合毛利率抬升不来自电池主业，A1 观察到的 2026H1 回落才是主业真实趋势。
  - **机制 B 分部成本与合并营业成本口径不一致**：F-gm-FY2025 用合并营业收入与营业成本计算，分部毛利率来自年报分产品表；若两者成本口径不同，「背离」是表述差异，不是经营现象。
  - 按底账三分部收入与毛利率做加权，结果低于综合毛利率，因此电池材料及回收分部毛利率跃升（F-materials-FY2025）不足以单独解释，不列为独立机制。
  - 线索假设（S3，非事实）：线索节称第四季度毛利率高于全年。若在年报中核实，需判断是否有集中在第四季度的一次性因素（第四季度收入与利润见 F-q4-FY2025）。
- 判别证据：

- A6 境外毛利率溢价能否持续：M=4，但现有披露难以分开准入壁垒、产品结构与汇率三种解释（D=2），入选分排第六，超出 5 个上限。A1 已使用境内外毛利率分化作为判别证据，部分覆盖。

- A8 现金充裕却大幅发债：M=2。资产负债率变化幅度小，融资结构本身不改变投资逻辑；募资用途已作为 A4 补充证据。
- A9 前五名客户集中度：M=2。占比 38.96% 未到改变逻辑的程度，且客户名称缺失短期难补。
- A10 资产减值与联营投资收益：M=2。扣非与归母在 FY2025 与 2026H1 增速同向同幅，暂不扭曲利润趋势。
- A11 汇兑损失：M=2。影响单期财务费用，不改变经营驱动。
- A12 2026H1 量价拆分（驱动缺口）：与 A1、A3 由同一份数据（2026H1 分产品 GWh 销量）判别，按规则合并，不单列。
