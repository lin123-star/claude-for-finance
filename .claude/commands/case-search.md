description: 在案例库中搜索案例。用法：/case-search [关键词]。支持按行业/结果/标签/公司名检索。
---

请调用 `case-library-agent` Agent 执行案例搜索操作。

## 执行指令

**操作类型**：搜索案例（SEARCH）

**传入参数**：用户在 `/case-search` 后面提供的关键词。

**搜索范围**：
- 行业标签（如：`PCB`、`新能源`、`消费电子`）
- 结果标签（如：`盈利`、`亏损`）
- 公司名（模糊匹配）
- 经验标签（如：`价格战`、`出口链`）

**执行步骤**：
1. 读取 `outputs/案例库/index.json`
2. 筛选 `sector`/`tags`/`result`/`name` 字段中包含关键词的条目
3. 读取匹配案例的"核心投资逻辑"和"可复用经验"章节
4. 输出匹配结果摘要

**若未提供关键词**：
> 请提供搜索关键词，例如：`/case-search PCB` 或 `/case-search 盈利`

**若案例库为空**：
> 案例库暂无记录。请先运行 `/case-add [公司名]` 新增第一条案例。
