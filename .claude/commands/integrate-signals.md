---

请调用 `signal-integrator` Agent，对指定公司的已有分析结论进行信号整合。

## 执行步骤

1. **定位材料**：读取以下路径下该公司的最新报告（或本轮对话中各 Agent 的输出）：
   ```
   d:\claude-for-finance\outputs\[公司名]\[公司名]-研究报告-*.md
   ```
   若找到多份报告，取日期最新的一份。若无报告文件，直接基于本轮对话中的 Agent 输出进行整合。

2. **执行整合分析**：按 signal-integrator 的完整流程执行：
   - Step 1：单维度审计（财务 + 竞争 + 估值 + 宏观）
   - Step 2：矛盾诊断（三路径解释 + 仲裁）
   - Step 3：综合信号评分（含权重调整）
   - Step 4：研究员追问清单（必问 ≤ 3 条，总计 5-8 条）
   - Step 5：整合摘要（置信度评级）

3. **输出**：直接在对话中展示完整结果。若用户要求保存，追加至：
   ```
   d:\claude-for-finance\outputs\[公司名]\[公司名]-研究报告-*.md
   ```
   在报告末尾新增章节 `## 信号整合分析 [YYYY-MM-DD]`。
