# 行业每周追踪命令

## 使用示例

```
/industry-weekly PCB
/industry-weekly 光模块,风电,精密电机
/industry-weekly all
```

## 执行流程

### Step 1：解析目标行业

- 若输入 `all`：追踪全部11个行业（适合周末批量运行）
- 若指定单个或多个行业：仅追踪对应行业
- `all` 模式下，按优先级顺序执行：先执行 watchlist 中 alert 状态的行业

### Step 2：加载 Skill

```
Read: d:\claude-for-finance\.claude\skills\industry-research\SKILL.md
```

对每个目标行业：
```
Read: d:\claude-for-finance\.claude\skills\industry-research\industries\[行业文件]
```

### Step 3：数据搜集（WebSearch）

对每个行业，按其行业文件中的"每周追踪 Prompts"执行搜索：
- 景气度核心数据（价格/产量/销量/装机量）
- 七天内政策动态
- 产业链上下游价格变化
- 关联标的公告/重要新闻

**搜索策略**：
- 优先搜索有明确数字的数据（而非泛泛评论）
- 标注信息来源和日期，不引用超过7天前的内容
- 无法搜索到的数据，明确标注"本周暂无更新数据"

### Step 4：信号识别

对每个行业，判断本周是否出现以下信号：
- 🔴 **景气恶化**：核心指标明显走差（价格下滑/库存积累/订单收缩）
- 🟡 **需关注变化**：有异常但方向不明确
- 🟢 **景气改善**：核心指标向好（价格回升/去库存/新订单增加）
- ⚪ **无重大变化**：平稳延续上周趋势

### Step 5：关联假设库更新（可选）

若发现某行业数据与 `outputs/假设库/[公司名]_假设追踪.md` 中的假设存在显著冲突，在周报中标注：

```
⚠️ 假设更新提示：[公司名] 的假设"[具体假设]"可能受到本周[数据/事件]影响，建议运行 /monitor [公司名] 进行详细核验。
```

### Step 6：输出周报

#### 单行业格式
```markdown
# [行业名] 周度追踪 - [YYYYMMDD]

## 景气信号：🟢/🟡/🔴

## 核心数据更新
| 指标 | 本周 | 上周/上月 | 变化 |

## 政策与产业动态

## 上下游价格变化

## 关联标的重要公告

## 与初始假设对比
⚠️ [如有假设更新提示]

## 下周关注事项
```

保存至：`d:\claude-for-finance\outputs\行业追踪\[行业名]-周报-[YYYYMMDD].md`

#### all模式汇总格式

在单行业详情报告基础上，额外生成一份汇总快览：
```
d:\claude-for-finance\outputs\行业追踪\全行业周报汇总-[YYYYMMDD].md
```

汇总格式：
```markdown

| 行业 | 信号 | 核心变化 | 关联标的提示 |

| 光模块 | 🟡 | 800G报价略有松动，关注Q3 | 中际旭创 |
...

## 本周最高优先级跟进事项
1. ...
2. ...
```
