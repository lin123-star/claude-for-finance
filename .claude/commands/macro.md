请调用 `macro-researcher` Agent 执行以下任务。

## 判断用法

**如果用户输入是 `/macro`（无附加参数）：**

执行完整宏观面板分析，包含：
- Part A：美林时钟定位（中国 + 全球当前象限）
- Part B：美国宏观矩阵（美联储 + 特朗普政策 + 美债 + 美元）
- Part C：中国宏观矩阵（货币 + 财政 + 社融 + 社零 + 利率汇率）
- Part D：综合研判（中美对比 + A 股环境总评 + 研究员追问清单）

输出标题：`# 宏观面板 [YYYY-MM-DD]`

若用户要求保存，存入 `d:\claude-for-finance\outputs\宏观研究\宏观面板-[YYYY-MM-DD].md`，目录不存在时自动创建。

---

**如果用户输入是 `/macro-brief [板块名]`（有板块参数）：**

执行针对该板块的宏观传导快速分析，聚焦以下问题：
1. 当前宏观周期对该板块是利多、中性还是利空？
2. 最关键的 2-3 个宏观变量是什么（及其当前状态）？
3. 需要重点监控的宏观风险事件？
4. 宏观视角下该板块未来 1-3 个月的配置方向？

**输出格式**：

```
# [板块名] 宏观传导分析 [日期]

## 宏观环境评级：🟢/🟡/🔴

## 核心宏观驱动变量

| 变量 | 当前状态 | 对[板块]影响 | 趋势 |
|------|---------|------------|------|
| [变量1] | | 利多/中性/利空 | |
| [变量2] | | | |
| [变量3] | | | |

## 利多因素
- [具体逻辑，有数据支撑]

## 利空/风险因素
- [具体逻辑，有数据支撑]

## 宏观视角配置建议
[1-3句综合判断，明确方向]

## 需追踪的宏观信号
1. [信号] — 预计披露时间：[时间]
2. [信号]
```

## 常见板块与关键宏观变量映射（参考）

| 板块 | 最关键宏观变量 |
|------|--------------|
| 新能源/光伏 | 美国关税政策、国内专项债/补贴、海外需求（欧美PMI）|
| 半导体/科技 | 美国出口管制、中国研发财政支持、美联储利率（估值端）|
| 消费/社零 | 社零增速、居民消费倾向、CPI 走势、LPR（房贷）|
| 地产/建材 | LPR 5Y、专项债投向、社融中长期居民贷款、政策支持力度 |
| 金融/银行 | 息差（LPR vs 存款利率）、信用利差、社融规模、不良率预期 |
| 出口/制造 | 美元指数、关税政策、海外 PMI、人民币汇率 |
| 大宗商品 | 全球 PMI、美元指数、中国基建投资、美联储政策预期 |
| 军工/国防 | 地缘政治、财政预算（国防支出）、政策表态 |
