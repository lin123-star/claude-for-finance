请调用 `case-library-agent` Agent 执行案例更新操作。

## 执行指令

**操作类型**：更新案例（UPDATE）

**传入参数**：用户在 `/case-update` 后面提供的公司名称。

**执行步骤**：
1. 在 `outputs/案例库/` 目录找该公司的案例文件
2. 若不存在，提示：
   > "[公司名]" 案例不存在。请先运行 `/case-add [公司名]` 新增案例。
3. 若存在，交互式引导用户更新：
   - **案例状态**：持续跟踪 / 已结束 / 已暂停关注（当前：[X]）
   - **实际结果**：盈利 / 亏损 / 持平 / 未知（当前：[X]）
   - **新增决策节点**：是否要在"关键决策节点"表新增一行？（输入事件描述）
   - **若状态=已结束**：引导填写"推演 vs 实际对比"和"成败因素分析"
4. 将用户输入的信息追加/更新到案例文件对应章节
5. 同步更新 `outputs/案例库/index.json` 中的 `result`/`status`/`grade` 字段

**若未提供公司名**：
> 请指定公司名，例如：`/case-update 胜宏科技`
