---
description: 查看案例库所有案例的概览列表。用法：/case-list
---

请调用 `case-library-agent` Agent 执行案例列表操作。

## 执行指令

**操作类型**：概览列表（LIST）

**执行步骤**：
1. 读取 `outputs/案例库/index.json`
2. 输出汇总表：

```
## 投研案例库概览  [日期]

| # | 公司 | 行业 | 状态 | 结果 | 评级 | 建研日期 |
|---|------|------|------|------|------|---------|
| 1 | ...  |      |      |      |      |         |

**统计**：共 N 条 | 持续跟踪 N 条 | 已结束 N 条 | 已暂停 N 条
**盈利率**：X%（仅已结束案例）
```

**若案例库为空**：
> 案例库暂无记录。运行 `/case-add [公司名]` 新增第一条案例。
