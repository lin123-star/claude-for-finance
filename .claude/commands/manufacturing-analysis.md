# 高端制造业专项分析命令

## 使用示例

```
/manufacturing-analysis 泰晶科技
/manufacturing-analysis 胜宏科技
/manufacturing-analysis 信维通信
```

## 适用范围

适合以下类型的 A 股制造业公司：
- 汽车零部件（拓普集团、旭升集团等）
- 半导体设备与材料（北方华创等）
- 光电子器件 / 光模块（中际旭创、光迅科技等）
- PCB / FPC（胜宏科技、沪电股份等）
- 精密制造（鸣志电器、泰晶科技等）

不适合：纯消费品公司、金融机构、互联网平台（这些公司用 `/analyze-company`）

---

## 执行流程

### Step 1：解析输入

从参数中提取公司名称。若未提供，询问：
> "请输入要分析的高端制造业公司名称（如：泰晶科技、胜宏科技）"

### Step 2：加载 Skill

加载分析框架：
```
Read: d:\claude-for-finance\financial-services-plugins\financial-analysis\skills\high-end-manufacturing-screener\SKILL.md
```

### Step 3：获取财报数据

按 Skill 中的数据获取规范，抓取最近 3 年年报 + 最近 4 个季报的核心财务数据。

数据获取完成后，向用户展示关键数据摘要并确认：
> "已获取 [公司名] 财务数据，数据截止 [季报日期]，关键指标如下：
> [展示营收增速、毛利率、应收/存货天数的简表]
> 确认无误后继续分析？"

### Step 4：执行五大分析模块

按顺序执行 Skill 中的五个模块：
1. **供应链地位分析**（约 2 分钟）
2. **产能健康度检查**（约 2 分钟）
3. **景气周期信号面板**（约 2 分钟）
4. **四大陷阱检查**（约 1 分钟）
5. **访调工作包生成**（约 3 分钟）— 基于前四个模块的具体发现定制生成

### Step 5：输出报告

将完整分析报告保存至：
```
outputs/[公司名]/[公司名]-制造业分析-[今日日期].md
```

若该目录不存在则自动创建。

完成后告知用户：
> "✅ 分析完成！报告已保存至 `outputs/[公司名]/[公司名]-制造业分析-[日期].md`
>
> **执行摘要：**
> [3-5句话核心结论]
>
> **访调工作包已生成**，优先级最高的访调目标是：
> [P1 访调对象及最关键的 1-2 个问题]"

### Step 6：假设写入（可选）

询问用户：
> "是否将本次分析提炼的核心假设写入假设追踪库？（输入 Y 确认）"

若确认，将 3-5 条关键假设追加写入：
```
outputs/假设库/[公司名]_假设追踪.md
```

若假设库文件不存在，则新建。
