请调用 `case-library-agent` Agent 执行新增案例操作。

## 执行指令

**操作类型**：新增案例（ADD）

**传入参数**：用户在 `/case-add` 后面提供的公司名称。

**执行步骤**：
1. 在 `outputs/[公司名]/` 目录找最新研究报告，读取核心投资逻辑、关键假设、目标价
2. 读取 `outputs/假设库/[公司名]_假设追踪.md`（若存在）
3. 生成标准案例文件，保存到 `outputs/案例库/[公司名]_案例_[今日日期].md`
4. 用 Python 更新 `outputs/案例库/index.json`（避免 PowerShell 编码问题）

**若未提供公司名**：
> 请指定公司名，例如：`/case-add 胜宏科技`

**支持附加参数**：
- `/case-add [公司名] --status=已结束`：同时标记为已结束
- `/case-add [公司名] --result=盈利`：同时记录投资结果
