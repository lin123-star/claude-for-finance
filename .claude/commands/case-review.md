请调用 `case-library-agent` Agent 执行复盘总结操作。

## 执行指令

**操作类型**：复盘总结（REVIEW）

**执行步骤**：
1. 读取 `outputs/案例库/index.json`，找出所有 `status == "已结束"` 的案例
2. 若无已结束案例，提示：
   > 当前案例库尚无"已结束"状态的案例，无法进行复盘总结。请在案例结束后，运行 `/case-update [公司名]` 更新案例状态。
3. 若有已结束案例，批量读取"推演 vs 实际对比"和"成败因素分析"章节
4. 按框架生成复盘总结（胜率概览 + 假设命中率 + 行业规律 + 时机规律 + 高频错误 Top 5 + SOP 改进建议）
5. 保存至 `outputs/案例库/案例库总结.md`（UTF-8，用 Python 写入），同时在对话中展示
