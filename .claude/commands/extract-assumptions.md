从已有研究报告中提取关键假设，写入假设库。

## 执行步骤

### Step 1：确定处理范围

**`/extract-assumptions`（无参数）：**
读取 `d:\claude-for-finance\outputs\假设库\index.json`，处理所有 `extracted: false` 的公司。

**`/extract-assumptions [公司名]`：**
只处理指定公司。

### Step 2：逐公司提取

对每家公司：

1. 读取对应的研究报告文件（路径从 index.json 的 `report_date` 和公司名推算）
2. 从报告中定位并提取以下内容：
   - **执行摘要**中的"核心投资逻辑"（3-5条）
   - **估值分析**中的核心财务预测假设（营收增速、毛利率、WACC、终值增速等）
   - **风险提示**中列出的 3-5 个主要风险
   - **投资建议**：目标价区间 + 投资评级

3. 按下方模板生成假设追踪文件，写入路径：
   ```
   d:\claude-for-finance\outputs\假设库\[公司名]_假设追踪.md
   ```

4. 更新 index.json，将该公司的 `extracted` 字段设为 `true`
