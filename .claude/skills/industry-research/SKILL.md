## 通用研究框架（所有行业适用）

### 行业入门：五步建立认知

**Step 1：产业链地图**
```
请描述[行业名]的完整产业链结构：
- 上游：核心原材料/零部件供应商，价格传导机制
- 中游：主要环节及头部企业（国内+海外）
- 下游：主要应用场景及终端需求驱动力
- 关键卡脖子环节（技术/产能/材料）
```

**Step 2：商业模式与竞争格局**
```
请分析[行业名]的商业模式和竞争格局：
- 主流商业模式（订单制/项目制/大宗品）
- 定价方式（成本加成/市场定价/招投标）
- 行业集中度（CR3/CR5），龙头护城河来源
- 国产化率现状及替代空间
- 进入壁垒（技术/资质/客户关系/产能规模）
```

**Step 3：景气周期驱动因子**
```
请分析[行业名]的景气周期：
- 核心需求驱动因子（1-3个最重要的）
- 供给端约束条件（产能/材料/设备）
- 历史景气周期规律（多少年一个周期？）
- 当前所处周期位置
- 领先指标：哪些数据能提前3-6个月预判景气度变化？
```

**Step 4：政策与监管环境**
```
请梳理[行业名]相关政策环境：
- 主要监管机构及核心政策法规
- 近两年重要政策变化及产业影响
- 政府补贴/退补情况
- 未来12-24个月政策方向预判
```

**Step 5：关键财务特征**
```
[行业名]的典型财务特征：
- 毛利率区间（龙头 vs 中小企业）
- 资产密集度（重资产/轻资产）
- 回款特征（账期/预付比例/坏账风险）
- CAPEX占收入比（扩张期 vs 成熟期）
- 估值方法（PE/PB/EV/EBITDA/PS，哪个更合理）
```

### 每周追踪：行业动态扫描模板

每周运行以下查询（配合 WebSearch）：

**1. 景气度数据**
```
搜索[行业名]本周：
- 最新价格指数（原材料/产品）
- 产量/销量数据（月频/周频）
- 行业协会最新发布数据
- PMI子项相关数据
```

**2. 政策与产业动态**
```
过去7天[行业名]相关：
- 国家/地方政策文件发布
- 重大招标/中标公告
- 头部企业产能投建公告
- 海外竞争格局变化（关税/反倾销）
```

**3. 上下游联动**
```
影响[行业名]的上游材料价格本周变化：
- [对应大宗商品]价格走势
- 供需缺口变化
- 下游需求端（[下游行业]）最新数据
```

**4. 公司层面事件**
```
以下公司本周公告或新闻：[对应关联标的列表]
- 业绩预告/快报
- 重大合同/订单公告
- 产能/扩产进展
- 高管变动/减持公告
```

## 执行说明

加载对应行业文件后，按需选择：
- **入门模式**：完整执行五步框架，输出行业研究笔记
- **周度追踪**：运行每周扫描模板，更新到 `outputs/行业追踪/[行业名]-[日期].md`

**输出路径**：
- 行业入门报告 → `d:\claude-for-finance\outputs\行业研究\[行业名]-入门-[YYYYMMDD].md`
- 每周追踪 → `d:\claude-for-finance\outputs\行业追踪\[行业名]-周报-[YYYYMMDD].md`
