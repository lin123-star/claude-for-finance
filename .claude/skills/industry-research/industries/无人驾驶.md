```
请描述无人驾驶行业完整产业链：
感知层（传感器）：
  - 激光雷达（LiDAR）：速腾聚创（RSLIDAR）、禾赛科技（Hesai）、图达通（用于特斯拉FSD之外）
  - 摄像头：索尼/三星CMOS，舜宇光学（车载镜头）
  - 毫米波雷达：博世/大陆/德尔福（外资）vs 苏州德佑/国内初创
  - 超声波：近距辅助停车，博世/法雷奥
计算层（算力）：
  - 整车域控：英伟达DRIVE Orin/Atlan → 英伟达Thor平台
  - 自研芯片：特斯拉FSD Chip（最强）、华为MDC610、地平线J5/J6、黑芝麻华山A2000
  - 座舱芯片：高通Snapdragon Cockpit（座舱主流）

  - 端到端：特斯拉FSD V12（最激进）、小鹏XNGP、华为ADS 3.0
  - 规则+数据融合：毫末智行、Waymo
整车集成：各OEM（比亚迪/理想/小鹏/华为系）
```

### 1.2 L2+/L4 竞争格局
```
无人驾驶竞争格局分析（L2+ vs L4分开看）：

L2+高阶辅助驾驶（当前主战场）：
  - 特斯拉FSD V12/V13：端到端神经网络，在美国强势，中国市场待监管落地
  - 华为ADS 3.0：问界M9等车型搭载，国内表现最强
  - 小鹏XNGP：城市NGP覆盖城市最广，数据积累强
  - 比亚迪天神之眼：中低端车型国产智驾民主化
  - Momenta/毫末：TO B供应商模式

L4 Robotaxi（商业化里程碑）：
  - Waymo（谷歌系）：旧金山/凤凰城商业运营，全球最成熟
  - 萝卜快跑（百度）：武汉大规模运营，中国最领先
  - 小马智行/文远知行：已在港股上市，收入规模小但商业化推进
  - 滴滴自动驾驶、AutoX

关键问题：L4何时实现大城市无安全员运营？中美监管进度对比如何？
```

### 1.4 端到端技术革命
```
端到端（End-to-End）技术路线对无人驾驶的影响：
传统路线 vs 端到端：
  - 传统：感知→预测→规划（三模块独立，规则驱动）
  - 端到端：输入传感器原始数据→直接输出驾驶动作（类似LLM的Scaling Law思路）

特斯拉FSD V12的意义：
  - 首个大规模商用端到端模型
  - 依靠全球400万辆特斯拉的实车数据飞轮
  - 无需精密高清地图（实现无图NOA）

国内跟进情况：
  - 小鹏：端到端神经网络XNet，"方舟架构"
  - 华为：统一大模型（DriveOne）进展
  - 理想、毫末智行：端到端落地进展

投资含义：
  - 传统Tier 1（博世/大陆的规则算法）护城河被削弱
  - 数据积累量=核心壁垒（谁有更多真实场景数据谁赢）
  - 激光雷达需求争议：纯视觉（特斯拉）vs 多传感器融合哪个会胜出？
```
