## 一、行业入门 Prompts

### 1.1 产业链结构
```
请描述AI芯片行业产业链：
上游：EDA工具（Synopsys/Cadence，国产：华大九天）、IP核（ARM/RISC-V）、
      先进制程代工（台积电/三星/中芯国际）、先进封装（CoWoS/HBM）
中游：AI芯片设计
  - 训练芯片：英伟达H100/H200/B100（统治地位）vs 华为昇腾910B vs 寒武纪MLU590
  - 推理芯片：英伟达L40S vs 华为昇腾310 vs 寒武纪云端推理系列
  - 端侧芯片：高通Snapdragon X/骁龙8系 vs 苹果Neural Engine vs 寒武纪边缘系列
下游：大模型训练（BAT/头部AI公司）、云计算服务商、智能终端
```

### 1.2 竞争格局
```
AI芯片竞争格局（重点中国市场）：
- 英伟达在中国市场：出口管制（A800/H800→限制→合规替代品）的影响
- 华为昇腾：910B/910C进展，是否能满足大模型训练需求
- 寒武纪：产品谱系（云端训练/云端推理/边缘/终端）、主要客户、收入结构
- 其他玩家：壁仞科技、摩尔线程、燧原科技、天数智芯
- 国产芯片的致命短板：HBM显存（SK海力士/三星，EUV光刻设备管制）
- 中国算力集群的"凑合方案"：国产GPU+存算分离+互联方案
```

### 1.3 政策与国产替代
```
AI芯片国产化政策环境分析：
- 美国出口管制：BIS规则演变历史（2022.10→2023.10→2024更新）
  对英伟达A100/H100/H800/A800的限制范围
  对HBM、EUV设备的管控
- 中国应对：举国体制支持（大基金/科技部专项）、"东数西算"工程
- 寒武纪等国产芯片的政府采购订单比例（是否依赖政策市场）
- 技术路线：RISC-V作为底层ISA的国产化意义
- 制裁升级路径：下一步美国可能的管制边界（SW算力限制）
```

### 1.4 技术差距与追赶路径
```
分析国产AI芯片（以寒武纪为例）与英伟达的技术差距：
- 算力（TFLOPS）：寒武纪MLU590 vs 英伟达H100 vs 华为910B的对比
- 软件生态：CUDA生态的护城河深度，国产芯片软件栈（寒武纪Bang C）的成熟程度
- 互联带宽：NVLink vs 华为High-Bandwidth Interface vs 国产方案
- 功耗效率：单位算力功耗对比
- 工程化能力：大规模集群（1000+卡）稳定运行能力
- 追赶时间估算：在什么条件下，国产芯片可以替代英伟达用于推理/训练？
```
