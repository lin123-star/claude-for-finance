# 消费电子供应链行业 Prompt 库

**关联标的**：信维通信（天线模组）、东山精密（FPC软板）
**行业定位**：苹果产业链核心，随AI手机新周期有望重估

---

## 一、行业入门 Prompts

### 1.1 产业链结构（以天线/FPC为核心）
```
请描述消费电子供应链（天线/FPC方向）的产业链结构：
天线模组：
- 上游：LCP/MPI基材（住友化学）、导电胶、金属弹片
- 中游：天线模组厂（信维通信、立讯精密-天线模块、安费诺-海外）
- 下游：苹果（iPhone系列天线方案变迁）、华为（5G复苏）、卫星通信新需求

FPC软板：
- 上游：FCCL覆铜板、PI膜（杜邦/达迈）
- 中游：FPC厂（鹏鼎控股、东山精密、弘信电子）
- 下游：智能手机、新能源汽车（线束替代方向）、折叠屏、AR/VR
```

### 1.2 竞争格局
```
信维通信/东山精密的竞争格局分析：
信维通信：
- 在苹果天线模组的份额（vs 立讯精密、安费诺）
- 卫星通信新业务：iPhone卫星天线的技术壁垒和商业化进展
- 汽车天线（V2X/卫星）的新业务开拓

东山精密：
- FPC在苹果链的份额（vs 鹏鼎控股、主要竞争对手）
- SLP（类载板）在旗舰机的渗透率（毛利率显著高于普通FPC）
- 印度建厂：跟随苹果产能转移，执行风险和回报预期
```

### 1.3 景气周期
```
消费电子供应链景气周期：
- 核心驱动：苹果iPhone年度新品发布周期（9月发布→Q4旺季）
- AI手机换机周期：iPhone 16/17的AI功能是否驱动换机超级周期？
- 华为复苏：Mate系列回归对国内品牌链的影响
- 折叠屏：三星/华为折叠屏放量对FPC量价的拉动
- 领先指标：
  ① 台湾代工厂（臻鼎/台郡）月营收（领先2-3个月）
  ② 苹果官方产品发布节奏
  ③ 郭明錤/天风证券供应链调研报告
```

### 1.4 卫星通信新主题
```
卫星通信对消费电子供应链的影响分析：
- iPhone卫星紧急SOS到卫星通信扩展的路线图
- 低轨卫星（Starlink/OneWeb/AST）商业化进展
- 国内低轨卫星（鸿雁/虹云）对国产手机引入卫星通信的时间表
- 卫星通信天线技术方案：PIFA天线 vs 相控阵天线，信维通信的技术储备
- SAT（手机直连卫星）标准（3GPP Release 17+）进展及对天线模组的需求拉动
```
