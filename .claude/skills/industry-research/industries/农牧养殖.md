# 农牧 / 养殖行业 Prompt 库

**关联标的**：巨星农牧（生猪养殖）
**行业定位**：强周期行业，核心是把握猪周期时点的投资机会

---

## 一、行业入门 Prompts

### 1.1 产业链结构
```
请描述生猪养殖行业产业链：
上游：
  - 饲料原料：玉米（全球定价，芝加哥期货）、豆粕（大豆压榨，与美豆相关）
  - 疫苗/兽药（科前生物/中牧股份）
  - 种猪（国内种猪库：PIC/丹系进口，国产化进展）
中游：生猪养殖
  - 散户（自养+外购仔猪育肥）vs 规模场（温氏/牧原/正邦/双胞胎）
  - 能繁母猪存栏量（核心供给指标）——能繁→配种（4个月）→分娩→育肥（6个月）→出栏
下游：屠宰（双汇发展/新希望）→肉制品加工→终端消费
中粮/雨润的垂直整合模式 vs 牧原的纯养殖 vs 温氏"公司+农户"
```

### 1.2 猪周期核心逻辑
```
猪周期的运行机理（关键概念梳理）：
- 完整周期：一般3-4年一个完整周期（从低谷到高峰再到低谷）
- 什么决定猪价：主要是供给（能繁母猪存栏量）决定12-14个月后的出栏量
- 能繁母猪存栏量的关键区间：正常值约4100万头（农业农村部公布），
  低于3800万→供给收缩信号；高于4500万→供给过剩信号
- 猪粮比（猪肉价格/玉米价格）：正常盈亏线约6:1；低于5.5:1为亏损区
- 请介绍2021-2026年猪周期各阶段的供求变化和猪价走势
- 巨星农牧的成本竞争力（完全成本）处于行业什么水平？
```

### 1.3 竞争格局
```
生猪养殖行业竞争格局：
- 行业集中度：前十大猪企出栏量占全国比例（行业集中度仍然偏低）
  牧原（年出栏6000万+）vs 温氏（4000万）vs 新希望（1500万）vs 巨星农牧（较小）
- 规模养殖的成本优势：牧原完全成本约14-15元/kg是行业标杆
- 巨星农牧的定位：区域龙头，四川大本营，成本结构如何？
- 散户加速退出：环保政策+非洲猪瘟后散户能否依赖规模化替代
- 猪价下行期的资产负债表比较：谁的负债率最低、现金流最充裕？
```

### 1.4 非洲猪瘟（ASF）长尾影响
```
非洲猪瘟对中国猪业的长期影响分析：
- 疫情现状：ASF是否已经地方性流行（endemic）？对养殖密度的限制
- 疫苗进展：ASF疫苗研发（科前生物/中国农科院）的商业化时间表
- 生物安全投入：规模场的楼房猪舍/多点式养殖对成本和防疫效果的影响
- 种猪更新：从进口丹系/PIC到国产大白二元母猪的替代进度
```

## 二、每周追踪 Prompts

## 三、猪周期时点判断框架

| 指标 | 底部信号 | 高点信号 |
|------|---------|---------|
| 能繁母猪存栏 | 连续6个月下降后企稳 | 连续6个月上升且>4500万 |
| 猪粮比 | <5:1（深度亏损，去化加速） | >8:1（暴利，扩张加速） |
| 头部猪企股价 | 跌破净资产 | PE>30x（透支预期） |
| 仔猪价格 | <300元/头（无人补栏） | >800元/头（疯狂补栏） |

**投资时点**：能繁母猪存栏连续下降6个月+猪粮比接近盈亏线→提前6-9个月布局

## 四、关键信息源

- **核心数据**：农业农村部官网（每月公布能繁母猪存栏、猪价数据）
- **期货价格**：大商所生猪期货（DCE.com.cn）
- **行业媒体**：猪好多网、新牧网、猪价网（每日现货价格）
- **竞品财报**：牧原股份月度销售数据是行业最重要的参考
- **国际参考**：USDA猪肉供需报告（全球猪肉贸易数据每月更新）
