# 核聚变行业 Prompt 库

**关联标的**：暂无直接A股纯正标的（参考：西部超导、应流股份、国机精工、联创光电）
**行业定位**：终极清洁能源，商业化拐点或在2030-2040年，当前为早期科技投资赛道

---

## 一、行业入门 Prompts

### 1.1 产业链结构
```
请描述核聚变行业产业链：
基础科学侧：
  - 国际大科学工程：ITER（国际热核聚变实验堆，法国，2025年调试）
  - 中国国家队：EAST（合肥，全超导托卡马克）、HL-3（西南物理所）、CFETR（十五五规划）
商业化侧（主要在海外）：
  - 磁约束托卡马克路线：Commonwealth Fusion Systems（CFS，美）、UKAEA/Tokamak Energy（英）
  - 惯性约束路线：NIF（美国国家点火装置，已实现净能量增益）、Marvel Fusion
  - 紧凑型球形托卡马克：TAE Technologies、Helion Energy（微软战略投资）
  - 中国商业：能量奇点（Energysingularity）、星环聚能、新奥集团
关键材料/设备：超导磁体（REBCO高温超导线材）、真空室、中子屏蔽材料、氚增殖堆载体
```

### 1.2 技术路线对比
```
核聚变主要技术路线深度比较：
1. 托卡马克（主流）：磁约束限制等离子体，ITER/EAST均采用
   优点：技术积累最深，科学可行性最强
   难点：超导磁体（高温超导REBCO带材成本）、等离子体稳定性、氚自持

2. 惯性约束（激光）：美国NIF于2022年12月实现点火（1.5倍能量增益）
   商业路径不明朗（激光效率低），主要作为科学工具

3. 紧凑型球形装置：CFS的SPARC（2025年点火目标），更小体积更强磁场
   若成功可大幅降低建造成本

4. 聚变-裂变混合堆：近期核聚变带动裂变，商业化过渡方案

关键问题：
- 目前全球距离"商业电站"还有多远？主流预测2035-2045年第一座商业聚变电站
- Q值（能量增益）的进展：从Q<1到Q>1到Q>>10的里程碑意义
- 氚的供应瓶颈：全球氚储量<20kg，聚变商用前必须实现氚自持（锂增殖）
```

### 1.3 投资逻辑（早期科技赛道）
```
核聚变的投资逻辑分析：
一级市场机会：
  - CFS（最受关注，已融资超20亿美元，SPARC项目2025年关键节点）
  - Helion Energy（微软签署购电合同，2028年目标，彼得·蒂尔支持）
  - TAE Technologies（Alphabet投资，聚变燃料特殊）

A股间接受益（技术/材料供应链）：
  - 西部超导：钛合金/超导材料，ITER中国采购份额
  - 应流股份：航空级铸件/特种材料（延伸核电高温合金）
  - 联创光电：光纤/激光器（惯性约束激光路线材料）
  - 国机精工：精密机械加工（真空室/偏滤器制造）

时间窗口判断：
  - 当前（2025-2030）：材料/装备企业受益ITER建设
  - 中期（2030-2040）：商业示范堆建设开始，工程化机会
  - 远期（2040+）：商业电站规模化，彻底改变能源格局

请评估：核聚变商业化的关键不确定性有哪些？投资的最大风险在哪里？
```
