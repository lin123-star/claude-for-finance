## 一、行业入门 Prompts

### 1.1 产业链结构
```
请描述光模块行业的完整产业链：
上游：核心光芯片（EML/VCSEL/DFB）、光探测器（PD/APD）、DSP芯片——国内外供应商现状
中游：光模块封装厂——全球市场格局（II-VI/Coherent、Lumentum、中际旭创、海信宽带、光迅科技、华工正源）
下游：数据中心（Meta/微软/谷歌/亚马逊）、电信运营商（5G承载）
技术路线：100G→400G→800G→1.6T迭代节奏，各带宽规格对应的应用场景
```

### 1.2 竞争格局
```
光模块行业竞争格局深度分析：
- 全球市场份额（中际旭创、海信宽带、华工科技 vs 海外竞争对手InnoLight、Lumentum）
- 中国厂商份额从2018年的约30%提升至今的过程及驱动因素
- 高速率（800G/1.6T）的技术壁垒与中美竞争关系
- CPO（共封装光学）技术路线对传统光模块的替代风险（英伟达Blackwell平台时间表）
- 客户集中度风险（中际旭创对Meta/微软的依赖程度）
```

### 1.3 景气周期
```
光模块行业景气周期与AI算力投资的关系：
- 核心驱动链条：超大规模云厂商CAPEX→GPU采购→网络设备（交换机）→光模块需求
- 英伟达GPU交付节奏对光模块需求的领先/滞后关系（一般3-6个月）
- 800G从放量到成熟需要多长时间？当前1.6T渗透率进展
- 电信侧需求（400G ZR+相干模块用于5G/城域网）能否对冲数据中心波动？
- 领先指标：云厂商财报中网络CAPEX指引、台湾代工厂（台积电）光芯片订单、AOC线缆出货量
```

### 1.4 技术趋势（最重要）
```
光模块行业未来3年最关键技术变革：
1. CPO（共封装光学）：英伟达Quantum-X平台vs传统可插拔模块路线之争
   - CPO何时大规模商用？对中际旭创/光迅科技的冲击程度？
   - CPO时代的产业链重构：谁受益？谁受损？
2. 硅光集成：英特尔硅光/台积电SiPh技术进展，对III-V族材料路线的挑战
3. 1.6T量产时间表：主要供应商（中际旭创/海信/华工）的准备程度
4. 短距AOC/AEC是否会部分替代光模块（英伟达NVLink应用场景）
```
