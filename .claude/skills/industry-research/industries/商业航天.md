# 商业航天行业 Prompt 库

**关联标的**：暂无直接标的（参考：天银机电、航天电器、华秦科技、中航光电）
**行业定位**：政策驱动+商业化快速起步，SpaceX模式国产化复制的核心赛道

---

## 一、行业入门 Prompts

### 1.1 产业链结构
```
请描述商业航天行业完整产业链：
上游：火箭发动机（液氧煤油/液氧甲烷/固体）、航天材料（碳纤维/钛合金/高温合金）、
      电子元器件（宇航级芯片/惯导/星敏感器）、地面测控设备
中游：
  - 运载火箭：可复用火箭（SpaceX Falcon 9模式）——国内（蓝箭/天兵/星际荣耀/深蓝航天）
  - 卫星制造：低轨通信卫星（GEO/LEO）、遥感卫星、科学卫星
  - 卫星互联网运营：Starlink（全球）vs 国内（千帆/鸿雁/吉利GeeSpace）
下游：卫星通信（宽带入网）、遥感数据服务（精准农业/城市规划/应急管理）、导航增强
国内外格局：与SpaceX/Blue Origin的代际差距，国内初创梯队
```

### 1.2 竞争格局
```
商业航天竞争格局分析：
全球：SpaceX Starlink已发射7000+颗卫星，一骑绝尘；亚马逊Kuiper尚在部署
国内梯队：
  - 火箭：蓝箭航天（朱雀2.0液氧甲烷，国内第一支商业液体火箭入轨）
           天兵科技（天龙2.0，密集发射）
           星际荣耀（双曲线系列）
           深蓝航天（可复用验证进展）
  - 卫星互联网：上海"千帆星座"（G60，目标1万颗）vs 央企鸿雁（中国卫通）
  - 遥感：长光卫星（吉林一号）、四维图新、欧比特
国家队 vs 商业队：航天科技/科工（国家队）对商业航天的态度变化
A股相关标的：航天电器、天银机电、振芯科技（卫星导航）、中国卫星
```

### 1.3 景气周期与驱动因素
```
商业航天景气度分析：
- 政策驱动：中国2015年开放商业航天后的政策演变，"新质生产力"定位
- 卫星互联网的商业化时间表：
  千帆星座首批卫星发射→商业服务开启→用户规模增长
  与Starlink在中国周边（东南亚/中东）的竞争
- 火箭可复用化：降低发射成本的关键（SpaceX从3万→600美元/公斤），国内进展
- 遥感数据商业化：政府/军事采购 vs 商业应用（保险/物流/金融）
- 领先指标：
  ① 国内商业火箭年度发射次数（全球商业航天数据库跟踪）
  ② 卫星互联网用户数（Starlink目前400万用户作为参照）
  ③ 国家发改委/工信部航天相关政策密度
  ④ 主要公司融资动态（Pre-IPO轮规模/估值）
```

### 1.4 技术趋势与关键节点
```
商业航天最重要的技术里程碑（2025-2028年国内）：
1. 可复用火箭：深蓝/蓝箭何时实现第一级回收？（参考SpaceX 2015年首次着陆）
2. 液氧甲烷发动机：朱雀3.0/天龙3.0进展（甲烷发动机是可复用的理想燃料）
3. 千帆星座部署节奏：2025年计划发射多少颗？组网最低可用规模是多少颗？
4. 卫星互联网终端国产化：相控阵天线（平板）成本从3000美元→降至300美元的时间线
5. 太空经济新前沿：太空制造/太空旅游/月球资源开发的商业化路径
```

## 三、投资逻辑框架

**一级市场视角**（主要投资机会）：
- Pre-IPO：蓝箭/天兵/星际荣耀（发射成功率和技术路线验证是核心）
- 供应链：耐高温材料（碳基复合材料）、精密阀门、惯性导航

**A股间接受益**：
| 标的 | 受益逻辑 | 核心风险 |
|------|---------|---------|
| 航天电器 | 宇航级连接器垄断 | 订单周期性 |
| 天银机电 | 火工品/分离机构 | 军品依赖 |
| 振芯科技 | 北斗/卫星导航芯片 | 竞争加剧 |
