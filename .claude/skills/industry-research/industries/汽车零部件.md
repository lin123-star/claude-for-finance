# 汽车零部件行业 Prompt 库

**关联标的**：拓普集团（底盘/热管理）、旭升集团（铝压铸）
**行业定位**：国产替代加速，跟随新势力崛起的核心受益环节

---

## 一、行业入门 Prompts

### 1.1 产业链结构
```
请描述汽车零部件行业结构：
一级供应商（Tier 1）：直接供整车厂，如博世/大陆/采埃孚/弗吉亚（外资）vs 拓普/旭升/福耀/伯特利（国内）
二级供应商（Tier 2）：向Tier 1供零部件，技术含量较低但量大
重点细分：底盘系统（制动/转向/悬架）、热管理、铝压铸轻量化、内外饰、电子电气架构
新能源增量：热管理价值量从传统车2000元→新能源5000-8000元；铝压铸一体化压铸带来新需求
```

### 1.2 竞争格局
```
汽车零部件（底盘/热管理/铝压铸）竞争格局：
- 外资Tier 1（博世/大陆/采埃孚）的市场份额变化趋势——国产替代节奏
- 国内Tier 1新势力时代的受益逻辑（新势力更愿意用国产供应商）
拓普集团：跟随特斯拉起家，向其他新势力扩展，热管理+底盘+轻量化三条腿
旭升集团：铝压铸起家，特斯拉依赖度高，向一体化压铸转型
- 一体化压铸技术：特斯拉引领，国内进展（文灿股份/旭升/立中集团）
- 热管理：三花智控/拓普/银轮的格局
```

### 1.3 景气周期
```
汽车零部件景气周期分析：
- 直接跟随整车销量，但新能源车单车价值量更高（对冲传统车下滑）
- 客户集中度风险：特斯拉/比亚迪/蔚小理订单占比过高的风险
- 产能扩张节奏：零部件厂资本开支重，回款周期长（账期60-90天）
- 领先指标：
  ① 特斯拉/比亚迪季度产量目标调整
  ② 新势力月度交付量
  ③ 整车厂产能利用率
  ④ 钢/铝价格（成本端）
```

### 1.4 技术趋势
```
汽车零部件行业最重要技术变革：
1. 一体化压铸：特斯拉Gigapress引领，减少焊接工序，降低重量
   - 当前国内一体化压铸渗透率？旭升的进展？
2. 热管理集成化：电动车热管理从分散到集成模块
3. 线控底盘：转向/制动全线控化，智能驾驶前提条件
4. 800V高压平台：对热管理/电控要求提升
5. 出海配套：跟随整车厂出海（拓普跟随特斯拉去德克萨斯）
```

## 三、拓普 vs 旭升对比追踪

| 维度 | 拓普集团 | 旭升集团 |
|------|---------|---------|
| 核心产品 | 底盘+热管理+轻量化 | 铝压铸+一体化压铸 |
| 第一大客户 | 特斯拉（约60%） | 特斯拉（约80%+） |
| 客户分散进展 | 理想/小鹏/国内整车 | 比亚迪/华为系 |
| 毛利率水平 | 约16-18% | 约20-24% |
| 核心风险 | 特斯拉砍单/降价压成本 | 特斯拉自制压铸/汇率 |

## 四、关键信息源

- **整车产销**：乘联会、中汽协月度数据
- **原材料价格**：SMM铝锭价、钢材价格指数
- **特斯拉动态**：Troy Teslike（交付数据追踪）、特斯拉官方财报
- **行业报告**：中国汽车工业协会零部件委员会
- **竞品追踪**：三花智控、银轮股份、文灿股份公告
