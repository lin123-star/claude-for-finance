## 一、行业入门 Prompts

### 1.1 产业链结构
```
请描述人形机器人行业产业链：
上游核心零部件：
  - 执行器（关节）：电机（伺服/空心杯）+ 减速器（谐波/RV减速器）+ 驱动器

  - AI芯片/算法：英伟达（Jetson Orin/Thor）、高通（机器人平台）、国内寒武纪/地平线
  - 结构件：铝合金/碳纤维骨架，精密铸造和机加工

  - 特斯拉Optimus（最重要参照系）
  - 国内：宇树科技（H1/G1/H1-2）、智元机器人（远征A2）、小鹏鹏行（IRON）
    优必选（Walker X）、傅利叶（GR-2）、达闼（HARIX）
下游：工厂（汽车/3C/物流）替代人力，家庭服务（长期）

### 1.3 景气周期（行业早期，关注里程碑）
```
人形机器人行业的关键里程碑（非传统周期，关注产品进展节奏）：

  ④ 工厂合作公告（大型车企/制造企业与机器人公司的合作协议）
  ⑤ 核心零部件（谐波减速器/六维力矩传感器）出货量

### 1.4 核心技术壁垒
```
人形机器人的核心技术壁垒分析：
1. 运动控制：全身动力学规划（能跑/能跳/摔倒后爬起来）
   - 当前水平：波士顿动力Atlas（液压，顶级但贵）vs 宇树H1（纯电，性价比高）
   - 关键技术：强化学习（RL）训练运动策略，仿真到现实的迁移

2. 操作智能（最难）：双手灵巧操作（拧螺丝/折叠衣服/搬运不规则物体）
   - 依赖：VLA（视觉-语言-行动）大模型，数据飞轮
   - 国内进展：具身智能大模型（清华/复旦/各公司自研）

3. 整机成本：
   - 谐波减速器：单台20-40个，每个约500-2000元，总成本占比30%
   - 六维力矩传感器：每台6-12个，每个约1万元，国产化率<20%
   - 电机+驱动：每台20-40个，约占15%成本

4. 能源：续航（锂电池，2-4小时），充电vs快换

请评估：哪个技术壁垒最难跨越？商业化落地最先在哪个场景实现？
```
