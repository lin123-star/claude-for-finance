# 新能源汽车行业 Prompt 库

**关联标的**：比亚迪
**行业定位**：全球最大新能源汽车市场，中国汽车产业弯道超车核心赛道

---

## 一、行业入门 Prompts

### 1.1 产业链结构
```
请描述新能源汽车行业完整产业链：
上游：锂/钴/镍（资源端）→电池材料（正极/负极/隔膜/电解液）→电芯制造→PACK
中游整车：纯电（BEV）/插混（PHEV/EREV）两种技术路线的优劣势对比
智能化：智驾芯片（英伟达/华为/地平线）、传感器（激光雷达/摄像头/毫米波）、座舱芯片
竞争格局：比亚迪、特斯拉、华为系（问界/阿维塔/智界）、小米、理想、蔚来、小鹏各自定位
```

### 1.2 比亚迪专项竞争分析
```
比亚迪在新能源汽车的竞争地位分析：
- 垂直整合程度（电池/芯片/电机/电控自制比例）及成本优势量化
- 各价格带（10万以下/10-20万/20-30万/30万以上）市场份额
- 刀片电池 vs 宁德时代麒麟电池的技术差异
- 仰望/方程豹高端化进展（对毛利率的拉升作用）
- 出口战略：进入哪些市场？在东南亚/欧洲/南美的竞争态势
- 王朝网 vs 海洋网 vs 腾势 vs 仰望的产品矩阵逻辑
```

### 1.3 景气周期
```
新能源汽车行业景气度分析：
- 月度销量数据解读框架（乘联会/中汽协口径差异）
- 新能源渗透率突破50%后的增长空间在哪里？（农村市场/换购需求/海外）
- 价格战持续性判断：何时见底？毛利率的底部在哪里？
- 领先指标：
  ① 乘联会月度新能源批发/零售数据（每月8-10日）
  ② 动力电池装机量（中汽协月度）
  ③ 碳酸锂价格（判断成本端压力）
  ④ 排产计划（乘联会/厂商官方）
```

### 1.4 政策环境
```
新能源汽车政策环境分析：
- 购置税减免/补贴政策现状及延续预期
- 欧盟对中国电动车关税政策（31.4%附加税）对比亚迪出口影响
- 充电桩建设政策（国家/地方）对渗透率的支撑
- 积分政策（双积分）对合资品牌转型压力
- 碳排放标准收紧时间表对传统车企的影响
- 美国《通胀削减法案》IRA对中国车企出海的限制
```

## 二、每周追踪 Prompts

### 2.1 销量与景气度
```
新能源汽车行业本周核心数据：
1. 乘联会最新周度/月度零售数据（新能源渗透率）
2. 比亚迪当月销量快报（月初5日内发布）
3. 竞争对手（理想/鸿蒙智行/小米）月度交付数据
4. 碳酸锂现货价格（上海有色网/SMM）
5. 新车型上市定价信息（是否引发新一轮价格战）
```

### 2.2 政策与产业动态
```
过去7天新能源汽车政策和产业动态：
- 工信部/发改委新政策/征求意见稿
- 重要出口市场（欧盟/东南亚）贸易政策变化
- 电池材料（碳酸锂/钴/镍）重大变化
- 智驾相关重大技术发布（华为/特斯拉FSD/比亚迪天神之眼）
```

### 2.3 比亚迪专项监测
```
比亚迪本周重要信息：
- 官方降价/价格调整公告
- 海外市场（欧洲/东南亚/澳洲）重大进展
- 供应链重大变化（宁德时代份额变化/自供电池占比）
- 高端品牌（仰望/方程豹）销量数据
- 二手车残值率（判断品牌力）
```

## 四、关键信息源

- **销量数据**：乘联会官网（pca.org.cn）、中汽协（caam.org.cn）
- **电池数据**：中国汽车动力电池产业创新联盟（月度装机量）
- **原材料价格**：SMM（有色金属网）、百川盈孚（碳酸锂）
- **政策文件**：工信部官网、发改委官网
- **竞品追踪**：各新势力官方微信号、懂车帝销量榜
