**关联标的**：泰晶科技
**行业定位**：电子元器件基础器件，5G/物联网/AI终端需求驱动的细分赛道

## 一、行业入门 Prompts

### 1.1 产业链结构
```
请描述石英频控（晶体振荡器）行业产业链：
上游：天然/人工合成石英晶体原料（国产化程度）
中游：频控产品细分
  - 晶体谐振器（XTAL）：最基础，用于信号参考
  - 晶体振荡器（XO/TCXO/VCXO/OCXO）：精度递增，价格递增10x—100x
  - 差分晶振：高端通信/服务器用
下游：5G基站、智能手机、物联网模组、汽车、数据中心服务器
国内外格局：日本（爱普生/日本电波工业/京瓷）vs 国内（泰晶/晶赛/惠伦）
```

### 1.2 竞争格局
```
石英频控行业竞争格局：
- 全球市场：日系厂商（爱普生、KDS、TXC）长期主导，国产替代空间
- 国内格局：泰晶科技 vs 晶赛微 vs 惠伦晶体
- 泰晶科技的产品结构：温补晶振（TCXO）占比几何？高端差分晶振进展如何？
- 国产替代程度：5G基站晶振国产化率？服务器晶振国产化率？
- 客户结构：泰晶的主要客户（华为/中兴/移远通信等）
- 新进入者威胁：TXC（台湾）等是否加大大陆市场竞争？
```

### 1.3 景气周期
```
石英频控行业景气周期分析：
- 5G基站建设周期（国内三大运营商年度资本开支）
- 智能手机出货量（每部手机含2-10颗晶振）
- 物联网/汽车电子（IoT量大价低，汽车价高精度要求高）
- AI终端/边缘计算新需求（服务器高精度晶振用量提升）
- 领先指标：
  ① 运营商5G资本开支规划
  ② 手机出货量数据（IDC月度）
  ③ 物联网模组出货量（移远通信/日海智能月度数据）
  ④ 爱普生/KDS财报（全球需求的晴雨表）
```

### 1.4 技术趋势
```
石英频控行业技术演进：
- MEMS振荡器（硅基振荡器）替代传统石英的威胁：
  SiTime（MEMS振荡器龙头）在服务器领域的渗透
  对泰晶等石英厂的冲击时间表和影响范围
- 5G mmWave毫米波对高精度TCXO的需求提升
- 汽车ADAS对车规级晶振（AEC-Q200认证）的认证壁垒
- 服务器时钟同步：差分晶振（单端→差分升级带来价格提升3-5x）
```

## 四、关键信息源

- **行业数据**：中国电子元器件行业协会、工信部电子信息司
- **5G建设数据**：国家统计局、三大运营商季报
- **竞品**：SiTime（MEMS，纳斯达克SITM）季报最能反映晶振市场全貌
- **产业追踪**：集微网、爱集微（电子元器件行业媒体）
- **价格数据**：中国电子市场（Cecimo数据库）
