# 风电行业 Prompt 库

**关联标的**：金风科技
**行业定位**：新能源主力电源，国家能源安全战略核心

---

## 一、行业入门 Prompts

### 1.1 产业链结构
```
请描述风电行业的完整产业链：
上游：主轴承（瓦轴/新强联）、齿轮箱（中国高速/南高齿）、叶片（中材科技/时代新材）、铸锻件（日月股份）、塔筒（天顺风能）、电控系统（禾望电气）——各细分供应格局
中游：整机制造商——国内格局（金风/远景/明阳/运达/东方电气/三一重能）及海外（维斯塔斯/西门子歌美飒）
下游：五大六小电力央企（国家能源/华能/华电/大唐/国电投/三峡集团），地方能源平台
```

### 1.2 竞争格局
```
风电整机竞争格局分析：
- 国内整机市场份额近三年变化（金风/远景/明阳/运达/东方电气/三一重能）
- 陆上 vs 海上风电毛利率差异及竞争格局差异（海上集中度更高）
- 大型化趋势：单机容量从3MW→5MW→8MW→15MW以上的迭代速度
- 价格战激烈程度：近两年陆上风机中标价从X元/千瓦下降至Y元/千瓦
- 出海机遇：金风科技海外布局vs维斯塔斯、歌美飒的竞争优势
- 一体化趋势：整机厂自制叶片/铸件对零部件供应商的影响
```

### 1.3 景气周期
```
风电行业景气周期分析：
- 装机量驱动因素：电力规划（十四五/十五五目标）、消纳政策、平价上网扩展
- 招投标→吊装周期（一般滞后6-12个月）
- 海上风电：受审批/海域使用权/电网接入影响，周期更长
- 领先指标：
  ① 风机招标量（BNEF/金风发布的月度招标数据）
  ② 国家能源局风电装机数据（月度）
  ③ 大风电集团年度采购计划
  ④ 海上风电并网量（判断确认收入节奏）
- 当前周期：十五五规划带来的装机目标提升预期
```

### 1.4 政策关键节点
```
风电行业政策环境深度分析：
- 十五五风电装机目标及年度分解
- 海上风电省级补贴退出时间表（广东/山东/浙江各省情况）
- 竞配上网（竞争性配置）对开发商回报率的影响
- 电力市场化改革：现货市场扩展对风电收益率影响
- "以大代小"政策：存量机组替换改造空间
- 碳市场对可再生能源的价值重估（CCER重启进展）
```

## 二、每周追踪 Prompts

### 2.1 景气度指标
```
风电行业本周景气度追踪：
1. 国家能源局最新风电装机数据（月频）
2. 本周风机招标公告（金额/容量/中标价格）
3. 全国弃风率数据（判断消纳情况）
4. 风电指数/龙头股（金风科技）最新公告
5. 钢材（塔筒）、碳纤维（叶片）价格变化
```

### 2.2 政策动态
```
过去7天风电政策动态：
- 国家能源局/发改委风电相关政策发布
- 省级海上风电项目审批/开工公告
- 电网公司接入相关规划调整
- 碳市场/绿电交易相关政策
```

### 2.3 产业链上下游
```
风电产业链上下游关键变化：
- 主轴承（瓦轴/新强联）供货节奏及价格
- 碳纤维（叶片）价格（中复神鹰/吉林化纤）
- 钢材/铸件价格对整机成本的影响
- 开发商（五大六小）新项目招标计划变化
```

## 四、关键信息源

- **装机数据**：国家能源局官网（月度）、北极星风力发电网
- **招标数据**：BNEF、风芒能源招标追踪
- **政策文件**：国家能源局官网政策库
- **产业研究**：CWEA（中国风能协会）年度报告
- **国际对比**：GWEC（全球风能理事会）季度数据
