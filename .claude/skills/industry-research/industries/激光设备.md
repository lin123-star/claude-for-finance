# 激光设备行业 Prompt 库

**关联标的**：华工科技
**行业定位**：激光制造+光通信器件双主业，工业激光国产化核心受益方

---

## 一、行业入门 Prompts

### 1.1 产业链结构
```
请描述激光设备行业产业链：
上游：激光器（光纤激光器/半导体激光器/CO2激光器）
  光纤激光器：锐科激光（核心PUMP，国内领先）、IPG（全球龙头，光源依赖进口）
中游：激光加工设备
  - 切割设备：激光切割机（大族激光/华工/海目星）
  - 焊接设备：汽车/动力电池激光焊（华工/凌云光）
  - 打标/标识：各类标识和精密加工
下游：钣金加工（通用工业）、动力电池（激光焊接/切割）、汽车制造、半导体封装
华工科技双主业：① 激光设备 ② 光通信器件（光模块/光分路器）
```

### 1.2 竞争格局
```
激光设备行业竞争格局分析：
全球：IPG Photonics（光纤激光器全球龙头）vs 国产化（锐科激光/创鑫激光）
国内设备：大族激光、华工科技、海目星激光、超快激光（联赢激光）
华工科技的竞争定位：
  - 激光设备：汽车/动力电池焊接的行业地位
  - 光通信：华工正源（光分路器全球TOP3），以及和华工科技分立后的关系
  - 信息通信：与电信运营商的网络建设配套
国产替代进展：IPG光纤激光器国产化（锐科）对设备厂的意义
```

### 1.3 景气周期
```
激光设备行业景气周期：
- 下游需求结构：金属切割（钣金通用）30%+动力电池焊接30%+汽车20%+其他
- 动力电池投资周期（2023年过剩→2025年后再平衡）对激光焊接需求的影响
- 钣金加工（中小企业）随制造业整体景气度波动
- 半导体/PCB精密激光加工（超快激光）的高速成长
- 领先指标：
  ① 锂电池设备订单量（先导/杭可/赢合科技指引）
  ② 钢材/金属加工PMI（影响通用切割需求）
  ③ 汽车制造业CAPEX（影响焊接设备需求）
  ④ 大族激光/海目星季度订单
```

### 1.4 光通信器件（华工科技第二主业）
```
华工科技光通信器件业务分析（华工正源）：
产品：PLC光分路器（Passive Optical Splitter）、BOSA/ROSA光收发组件
市场地位：PLC光分路器全球前三（市占率>20%）
下游：运营商FTTH建设（PON网络）、数据中心AOC
景气度：与运营商宽带建设CAPEX直接相关
国际市场：PLC分路器出口比例高，受益于全球运营商FTTH铺设（印度/东南亚市场）
区别于光模块：分路器技术壁垒低，主要靠规模和成本；但华工有品牌和认证优势
```
