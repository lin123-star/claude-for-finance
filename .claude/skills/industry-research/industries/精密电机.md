**关联标的**：鸣志电器

## 一、行业入门 Prompts

### 1.1 产业链结构
```
请描述精密电机（步进电机/伺服电机）行业产业链：
上游：稀土磁材（钕铁硼——中科三环/金力永磁）、铜线、硅钢片
中游细分：
  - 步进电机：结构简单，开环控制，价格低，鸣志电器全球领先
  - AC/DC伺服电机：闭环控制，精度高，多用于工业机器人
  - 直线电机/力矩电机：特殊场景（半导体光刻/激光切割）
驱动器/控制器：与电机配套，鸣志电器"电机+驱动+控制"一体化战略
下游：工厂自动化设备、3C制造、半导体设备、医疗设备、人形机器人
```

### 1.2 竞争格局
```
精密电机行业竞争格局分析：
步进电机：
  - 全球：日本（东方马达/日本伺服）vs 鸣志电器（中国最大）vs 雷赛智能
  - 鸣志电器全球市场份额估计及核心竞争优势（精度/服务/性价比）
  - 与东方马达的直接竞争关系——在哪些细分市场鸣志更强/更弱？

伺服电机（新战场）：
  - 竞争对手：汇川技术、台达（台湾）、西门子/安川（外资）
  - 国产化率现状（伺服约30-40%国产，步进约60-70%）
  - 鸣志的伺服进展：是否正在抢占外资份额？

人形机器人新赛道：
  - 鸣志的关节电机/空心杯电机在机器人的应用进展
  - 与Tesla Optimus/宇树/智元的合作情况
```

### 1.3 景气周期
```
精密电机景气周期分析：
- 核心驱动：制造业自动化CAPEX（工业机器人安装量）
- 全球制造业PMI与电机需求的关系
- 中国出口自动化设备（锂电池设备、光伏设备）带动电机需求
- 人形机器人：特斯拉Optimus量产节奏（2025/2026年目标），对关节电机的需求拉动
- 领先指标：
  ① 中国工业机器人月度产量（工信部）
  ② 制造业PMI生产/新订单分项
  ③ 工业自动化设备上市公司订单指引（汇川/埃斯顿等）
  ④ 人形机器人发布/量产公告
```

### 1.4 人形机器人专题
```
人形机器人对精密电机行业的影响分析：
- 人形机器人关节电机需求：关节数量（20-40个）× 每个电机种类（空心杯/伺服/步进）
- 鸣志电器目前在人形机器人的进展：哪些机型配套？营收占比？
- 壁垒：空心杯电机 vs 外转子电机 vs 谐波减速器组合方案
- 竞争者：江苏雷利、瑞驰电气在机器人电机的布局
- 2025-2026年人形机器人量产节奏：特斯拉/宇树/智元/小鹏鹏行
- 对鸣志电器营收的弹性估算（假设人形机器人量产X万台）
```
